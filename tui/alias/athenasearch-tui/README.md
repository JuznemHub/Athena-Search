# athenasearch-tui

Alias for [`athena-tui`](https://www.npmjs.com/package/athena-tui) — Terminal
UI for Athena Search. This package only re-exports it, so `athenasearch-tui`
and `athena-tui` install the same CLI:

```sh
npm install -g athenasearch-tui
athenasearch-tui        # or: athena-tui
```

See [`../README.md`](../README.md) for the full docs.
